# 换位实验判读标准

主比较：同一模型、同一历史快照，A 与 B 两个标签条件的决策说明。

- 明确事实错误：对已发生出拳、次序、次数、比分或身份的断言，与输入记录矛盾。
- 明确规则错误：声称某拳克制另一拳，但与石头胜剪刀、剪刀胜布、布胜石头矛盾。
- 不将猜测未命中、短样本推断、一般性风险评价或策略不佳自动计为事实错误。
- 无明确错误不等于模型理解正确：输出可能没有提到可检查的事实。
- 只评估最终 decision_summary；提供方的 reasoning 文本可用性不同，不用于双方错误率比较。
- 每份响应最多计一次“含明确错误”，另记录错误类别、具体原文和输入证据。
- 无效响应或网络失败单独列出，不计为内容正确，也不静默补抽。
- 动作变化是次要观察指标；不同重复之间存在采样波动，不能把一对不同动作直接归因于位置。

此实验不推进比赛，因此没有胜率指标。三次重复、两个历史快照只能提供探索性证据，不进行总体因果断言。原始历史中模型自己先前的错误说明保留，不能把结果解读为完全排除了错误历史自我强化。
